## QuaverStreamCompanion v0.1.0-rc2

Second release candidate. `qsc` reads the files Quaver already writes (`Logs/runtime.log` and `quaver.db`, opened read-only) and turns them into live data for your stream: browser-source overlays for OBS, a local dashboard, and a small event API. Nothing is injected into the game and nothing leaves your machine.

### What is new since rc1

- **More reliable in long sessions:** a score that Quaver writes late no longer delays the next map, overlays and the dashboard resync after a reconnect or a restart of `qsc`, and restoring an older Quaver database does not hide new plays.
- **Support tools:** a log file next to the config, `qsc doctor --report` and a Copy diagnostics button that hide your user folder name, a clear message when the port is already used, and `qsc -h`.
- **Safer by default:** the lane key stream is readable only by the overlays served by `qsc` itself, event streams are limited, built-in overlays run under a Content Security Policy, and the binaries are built with a patched Go toolchain. Third party licenses ship in every archive.
- **Dashboard polish:** an offline banner, translated errors, a skip link, numbers formatted by language, a page for OBS that fits small screens, and overlays that keep their layout with very long titles.

### Highlights

- **Seven overlays:** now playing, result card, accuracy history, game state badge, personal best / full combo alert, lane keys with KPS, and a judgment curve of the last play.
- **11 themes:** Neutral Light and Dark, Catppuccin Mocha and Latte, Tokyo Night, Dracula, Nord, Gruvbox, Rose Pine, Pixel and Neon Cosy. Add your own theme or your own overlay by dropping files in the config folder.
- **Dashboard** at `http://127.0.0.1:7878/` in English, French and German: live status, overlay links with recommended OBS sizes, play history, settings and an OBS setup guide.
- **Starts even when Quaver is missing,** explains what to fix, and connects on its own once the game folder is found.
- **Quit cleanly:** a Quit button in the dashboard settings and a `qsc stop` command, no console needed.
- **Opt-in lane keys and KPS** (Windows only for now): off by default, only the lane keys you choose are read, only while a map is being played, nothing is stored or logged.

### Status of this candidate

- Tested on Windows with a live Quaver install.
- The Linux builds pass the automated tests on Ubuntu, but have not been run with a real Steam and Proton install yet. The AppImage and the systemd user unit have not been run on a real machine either.
- Lane keys and KPS are not available on Linux yet.
- Replay analysis and the online Quaver API are intentionally not part of this release.

Bug reports and feedback are welcome, especially from Linux and Proton setups. Run `qsc doctor --report` and read it before sharing: the Quaver log excerpt can contain your player name.
