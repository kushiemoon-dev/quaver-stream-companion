## QuaverStreamCompanion v0.2.0

Text files for OBS, session statistics, map details and a website with a live demo of the overlays. `qsc` reads the files Quaver already writes (`Logs/runtime.log` and `quaver.db`, opened read-only) and turns them into live data for your stream. Nothing is injected into the game and nothing leaves your machine. QuaverStreamCompanion is an unofficial tool and is not affiliated with Quaver.

### What is new since v0.1.1

- **Text for OBS Text sources:** tick **Write the now playing text files** in Settings and `qsc` keeps `title.txt`, `artist.txt`, `difficulty.txt`, `mapper.txt`, `nowplaying.txt`, `last_grade.txt` and `last_accuracy.txt` in a `text` folder next to the config file. The same texts are served at `/api/text/<file>`. Off by default, and nothing is written to the Quaver folder.
- **Session statistics:** a new eighth overlay (`/overlays/session/`, 480 x 170) shows plays, passes, fails, average and best accuracy, best rating, full combos and pass streaks since `qsc` started. A **Reset the session** button is on the Status page. The numbers are in `GET /state` as `session` and in a new `session.updated` event.
- **Map details:** the map object now carries the mapper, BPM, length, note counts, ranked status, play count and online ids. The now playing overlay can show them on one line with `?meta=1` (a **Map details** checkbox on the Overlays page); BPM and length follow the play rate.
- **Demo preview:** the Overlays page has a **Preview with demo data** switch, so you can style the overlays before Quaver is running. It never changes the link you copy for OBS. The Status page points to it when Quaver is not found.
- **Website:** [quaver.kushie.dev](https://quaver.kushie.dev/) runs the real overlays in frames with a theme and language picker and a simulator of made-up plays. The overlay option `feed=parent` lets a page of the same origin send the events to a framed overlay.
- **Fixes:** several ticked states in the overlay `hide` list are all kept in the link, and the preview frame is named after what it shows.
- **Under the hood:** the overlay scripts moved to `page.js` files, and the JavaScript is now covered by tests (38.6 to 100 percent of lines) with minimum coverage enforced in CI.

All events and fields are additive: nothing that existed in v0.1.1 changed.

### Good to know

- Tested on Windows with a live Quaver install. On Linux, qsc is tested in CI with simulated Steam folders; it has not been confirmed with a real Quaver install, native or under Proton, and lane keys and KPS are not available on Linux yet.
- To update, quit `qsc` (the Quit button in Settings, or `qsc stop`), replace the program, and start it again. Your settings are kept.
- The website loads its fonts from Google Fonts. The program itself makes no network request.
- Replay analysis and the online Quaver API are intentionally not part of this release.

Run `qsc doctor --report` and read it before sharing it in a bug report: the Quaver log excerpt can contain your player name.
