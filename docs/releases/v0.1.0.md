## QuaverStreamCompanion v0.1.0

First stable release. `qsc` reads the files Quaver already writes (`Logs/runtime.log` and `quaver.db`, opened read-only) and turns them into live data for your stream: browser-source overlays for OBS, a local dashboard, and a small event API. Nothing is injected into the game and nothing leaves your machine. QuaverStreamCompanion is an unofficial tool and is not affiliated with Quaver.

### Highlights

- **Seven overlays:** now playing, result card, accuracy history, game state badge, personal best / full combo alert, lane keys with KPS, and a judgment curve of the last play.
- **11 themes:** Neutral Light and Dark, Catppuccin Mocha and Latte, Tokyo Night, Dracula, Nord, Gruvbox, Rose Pine, Pixel and Neon Cosy. Add your own theme or your own overlay by dropping files in the config folder, with a guide for each.
- **Dashboard** at `http://127.0.0.1:7878/` in English, French and German: live status, overlay links with recommended OBS sizes, play history, settings and an OBS setup guide.
- **Real score data:** rate, mods, personal bests per map, speed and mod set, failed and paused plays recognised, and an accuracy curve of the last play.
- **Reliable in long sessions:** late database rows, restarts of `qsc` and a restored database are handled, and overlays resync by themselves after a reconnect.
- **Starts even when Quaver is missing,** explains what to fix, and connects on its own once the game folder is found.
- **Easy to stop and to support:** a Quit button and `qsc stop`, a log file, and `qsc doctor --report` that hides your user folder name.
- **Opt-in lane keys and KPS** (Windows only for now): off by default, only the lane keys you choose are read, only while a map is being played, nothing is stored or logged.
- **Careful by default:** the local server only answers on `127.0.0.1`, built-in overlays run under a Content Security Policy, and third party licenses ship in every archive.

### Good to know

- Tested on Windows with a live Quaver install. The Linux builds pass the automated tests on Ubuntu, but have not been run with a real Steam and Proton install yet, and the same goes for the AppImage and the systemd user unit. Reports from Linux and Proton setups are very welcome.
- Lane keys and KPS are not available on Linux yet.
- Replay analysis and the online Quaver API are intentionally not part of this release.

Run `qsc doctor --report` and read it before sharing it in a bug report: the Quaver log excerpt can contain your player name.
