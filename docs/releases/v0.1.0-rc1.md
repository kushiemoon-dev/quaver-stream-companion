## QuaverStreamCompanion v0.1.0-rc1

First release candidate. `qsc` reads the files Quaver already writes (`Logs/runtime.log` and `quaver.db`, opened read-only) and turns them into live data for your stream: browser-source overlays for OBS, a local dashboard, and a small event API. Nothing is injected into the game and nothing leaves your machine.

### Highlights

- **Seven overlays:** now playing, result card, accuracy history, game state badge, personal best / full combo alert, lane keys with KPS, and a judgment curve of the last play.
- **11 themes:** Neutral Light and Dark, Catppuccin Mocha and Latte, Tokyo Night, Dracula, Nord, Gruvbox, Rose Pine, Pixel and Neon Cosy. Add your own theme or your own overlay by dropping files in the config folder.
- **Dashboard** at `http://127.0.0.1:7878/` in English, French and German: live status, overlay links with recommended OBS sizes, play history, settings and an OBS setup guide.
- **Real score data:** rate, mods, personal bests per map, speed and mod set, failed and paused plays recognised.
- **Starts even when Quaver is missing,** explains what to fix, and connects on its own once the game folder is found.
- **Quit cleanly:** a Quit button in the dashboard settings and a `qsc stop` command, no console needed.
- **Opt-in lane keys and KPS** (Windows only for now): off by default, only the lane keys you choose are read, only while a map is being played, nothing is stored or logged.

### Status of this candidate

- Tested on Windows with a live Quaver install.
- The Linux builds pass the automated tests on Ubuntu, but have not been run with a real Steam and Proton install yet. The AppImage and the systemd user unit have not been run on a real machine either.
- Lane keys and KPS are not available on Linux yet.
- Replay analysis and the online Quaver API are intentionally not part of this release.

Bug reports and feedback are welcome, especially from Linux and Proton setups.
