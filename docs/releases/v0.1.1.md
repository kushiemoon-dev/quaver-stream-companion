## QuaverStreamCompanion v0.1.1

Fixes for Linux and for every Quaver key mode, and data that follows the game more closely. `qsc` reads the files Quaver already writes (`Logs/runtime.log` and `quaver.db`, opened read-only) and turns them into live data for your stream. Nothing is injected into the game and nothing leaves your machine. QuaverStreamCompanion is an unofficial tool and is not affiliated with Quaver.

### What is new since v0.1.0

- **Linux:** `qsc` finds the native Linux build of Quaver (the executable is named `Quaver`), and the AppImage runs every command (`doctor`, `stop`, `version`). CI now starts `qsc` for real on Ubuntu (amd64 and arm64) and Windows against synthetic Steam folders (native, Flatpak, Snap, symlinked and extra libraries).
- **Every key mode:** lane keys and the keys overlay support 1K to 10K and the scratch lane of the 7K+1 modes, with lane keys per layout in the Settings page. Existing `k4` and `k7` settings keep working.
- **Closer to what Quaver does:**
  - Every screen is its own state (editor, download, importing, lobby, multiplayer, music, theatre), and a new `play.ended` event tells when a play ended without a saved score.
  - Plays are ranked like Quaver's local leaderboard (`local_rank`, `local_total`, a Best badge), next to the same speed personal best.
  - `played_at` is a full timestamp with the local offset (`played_at_raw` keeps the original text).
  - A crash of Quaver is noticed from the names of running programs (opt-out setting in Settings, nothing stored or sent).
- **Fixes:** custom themes written without spaces keep their colors in the dashboard, and a duplicate key in `config.json` can no longer override a saved setting.

### Good to know

- Tested on Windows with a live Quaver install. On Linux, qsc is tested in CI with simulated Steam folders; it has not been confirmed with a real Quaver install, native or under Proton, and lane keys and KPS are not available on Linux yet.
- A date read from `played_at` was the raw text in v0.1.0: read `played_at_raw` if you need the old value.
- Replay analysis and the online Quaver API are intentionally not part of this release.

Run `qsc doctor --report` and read it before sharing it in a bug report: the Quaver log excerpt can contain your player name.
